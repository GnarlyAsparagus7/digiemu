## Fixed points worth knowing

| address | what |
|---|---|
| `0x40000000` | VBR — the interrupt vector table (256 vectors). It is
  written at run time and is **not** in the firmware image |
| `0x40000400` | MAIN OS load address (section id 3) |
| `0x03000900` | bootstrap `dest` (section id 2) — but for the
  bootstrap this field is a version word, not an address |
| `0x80000400` | updater load address (section id 4) |
| `0x48000000` | initial stack pointer, per earlier measurement |
